# Aiffel

Orchestrateur conversationnel pour l'exploitation agricole : l'agriculteur parle à ses agents sur Telegram
(puis sur le web et le mobile), et Aiffel lit et écrit dans les logiciels de la ferme (Ekylibre, Lexicon…)
avec une validation humaine avant chaque écriture.
